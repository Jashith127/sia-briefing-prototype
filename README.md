# Sia's Briefing · Prototype

A clickable, static prototype of the Sia briefing page (sidebar and briefing only), with mock data.

- **Live:** served by GitHub Pages from `index.html`.
- **Layouts:** switch between Classic, Classic 2, Assistant, Brief and Message with the toggle in the page header.
- **Intro:** plays on load; **Replay intro** in the header runs it again.
- **Theme:** the button at the bottom right switches light and dark mode.

This is a rendered snapshot of the app with mock data, so actions such as assigning an issue or asking Sia are not live.
